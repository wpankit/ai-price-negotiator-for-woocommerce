# Getting help

- **Setting up or using the plugin:** ask on the [WordPress.org support forum](https://wordpress.org/support/plugin/ai-price-negotiator-for-woocommerce/).
- **A bug or an idea:** open an [issue](https://github.com/wpankit/ai-price-negotiator-for-woocommerce/issues/new/choose).
- **A security issue:** follow the [security policy](SECURITY.md) and report it privately.
